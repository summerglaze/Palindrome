# Palindrome Checker (JavaScript, HTML, CSS)

A small **web application** that checks if a **word or phrase** is a palindrome.  
The app ignores punctuation and spaces when checking, so you can type phrases like `"A man, a plan, a canal, Panama"` and it will correctly identify them as palindromes.

## Features
- Input field for a word or phrase.  
- Ignores spaces, punctuation, and capitalization.  
- Instant result displayed after submission.  
- Simple and responsive UI using HTML and CSS.

## Tech stack
- **CSS** ~40.8%  
- **JavaScript** ~37.4%  
- **HTML** ~21.8%
